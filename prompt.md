# Premium EdTech Landing Website (React + Tailwind CSS + Framer Motion)

## ROLE

You are a senior UI/UX designer and senior React frontend engineer with experience building award-winning SaaS and EdTech websites. Your goal is to create a premium, modern, human-designed landing page inspired by high-end websites like MuseConnect, Linear, Notion, Framer, Stripe, and Webflow—not an AI-generated template.

The website must feel handcrafted, elegant, minimal, trustworthy, and visually stunning.

---

# TECH STACK

Build everything using:

* React (Vite)
* Tailwind CSS
* Framer Motion (very subtle animations only)
* Lucide React Icons
* Fully Responsive (Mobile, Tablet, Desktop)

Do NOT use Bootstrap, Material UI, Chakra UI, or component libraries.

Use reusable React components.

Folder structure should be clean and scalable.

# ANIMATION RULES (IMPORTANT)

This is the most important requirement.

The website SHOULD NOT be animation-heavy.

Animations must feel natural and premium.

Allowed:

* Fade Up on Scroll
* Small Slide Up
* Slight Scale (1.02)
* Hover Lift (6px)
* Button Hover
* Image Parallax (very tiny)
* Number Counter

Duration:

0.3s–0.6s

Ease:

easeOut

Never animate every element.

Do NOT create bouncing icons.

Do NOT create spinning gradients.

Do NOT create continuous floating everywhere.

Maximum one floating animation inside Hero only.

Everything else should remain elegant.
